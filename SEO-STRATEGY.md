## 5. On-Page SEO Template

For every page on the site, follow this template:

```
Title Tag:        [Primary Keyword] — [Modifier] | ElianaTech
                  Max 60 characters

Meta Description: [Value proposition with primary keyword. Include CTA.]
                  Max 155 characters

URL:              /[category]/[primary-keyword-slug]

H1:               [Primary keyword or close variation — one per page]

H2s:              [Secondary keywords and related topics]

Image Alt Text:   [Descriptive text including keyword where natural]

Internal Links:   2+ links to related pages/articles

External Links:   1–2 links to authoritative sources
```

### Example

```
Title Tag:        Cloud Migration Services — AWS, Azure & GCP | ElianaTech
Meta Description: Migrate to the cloud with confidence. ElianaTech provides
                  end-to-end cloud migration services for AWS, Azure, and GCP.
                  Get a free assessment.
URL:              /services/cloud-infrastructure
H1:               Cloud & Infrastructure Services
H2s:              Cloud Migration Strategy, Managed Cloud Services,
                  Infrastructure as Code, Multi-Cloud Solutions
```

## 6. Technical SEO Checklist

### Site-Wide

- [ ] SSL/HTTPS on all pages
- [ ] XML sitemap submitted to Google Search Console
- [ ] Robots.txt configured correctly
- [ ] Canonical tags on all pages
- [ ] Hreflang tags (if multi-language planned)
- [ ] Structured data (Organization, Article, FAQ, BreadcrumbList)
- [ ] Open Graph tags for social sharing
- [ ] Twitter Card meta tags
- [ ] Favicon and web app manifest
- [ ] 404 page with navigation

### Performance

- [ ] Images compressed and served in WebP/AVIF
- [ ] Lazy loading for below-the-fold images
- [ ] CSS/JS minified and bundled
- [ ] CDN configured
- [ ] Core Web Vitals passing (LCP < 2.5s, FID < 100ms, CLS < 0.1)
- [ ] Gzip/Brotli compression enabled
- [ ] Browser caching configured

### Crawlability

- [ ] Clean URL structure (no parameters for content pages)
- [ ] No orphan pages (every page linked from at least one other page)
- [ ] Breadcrumb navigation on all pages
- [ ] Pagination implemented with rel="next"/"prev" or load-more
- [ ] No duplicate content issues
- [ ] 301 redirects for changed URLs

5. Technical issues found and resolved
