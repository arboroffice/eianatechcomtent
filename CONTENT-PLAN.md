## 3. Target Audience

### Primary Personas

**Persona 1 — Technical Decision-Maker**
- Role: CTO, VP of Engineering, Tech Lead
- Needs: Evaluating technology solutions, staying current with trends
- Content preference: In-depth technical articles, case studies, whitepapers

**Persona 2 — Business Stakeholder**
- Role: CEO, COO, Product Manager
- Needs: Understanding ROI of technology, competitive advantage
- Content preference: Executive summaries, outcome-focused case studies, industry reports

**Persona 3 — Developer / Practitioner**
- Role: Software Engineer, DevOps, Data Engineer
- Needs: Tutorials, implementation guides, best practices
- Content preference: How-to guides, code examples, technical deep-dives

## 6. Core Page Content Requirements

### 6.1 Homepage

**Purpose:** First impression. Communicate who ElianaTech is and the value it delivers.

**Content blocks:**
- Hero section: headline, subheadline, primary CTA
- Value proposition (3–4 pillars)
- Featured services overview
- Social proof (logos, testimonials, metrics)
- Latest blog posts (3 most recent)
- CTA banner (contact / demo)

**Word count target:** 500–800 words of body copy

---

### 6.2 About Page

**Purpose:** Build trust and tell the company story.

**Content blocks:**
- Company origin story
- Mission and vision statements
- Core values (3–5)
- Team section (photos, bios, roles)
- Timeline / milestones (optional)
- CTA to contact or careers

**Word count target:** 600–1,000 words

---

### 6.3 Services Overview Page

**Purpose:** Present all service offerings at a glance.

**Content blocks:**
- Services intro paragraph
- Service cards (icon, title, short description, link to detail page)
- Differentiators section
- Process overview (how we work)
- CTA to get in touch

**Word count target:** 400–600 words

---

### 6.4 Individual Service Pages

**Purpose:** Deep-dive into each service offering.

**Content blocks:**
- Service description
- Key benefits (bullet points)
- Use cases / who it's for
- Technology stack or approach
- Related case study
- FAQ section (3–5 questions)
- CTA to contact / request proposal

**Word count target:** 800–1,200 words each

---

### 6.5 Case Studies

**Purpose:** Demonstrate real results for real clients.

**Template structure:**
1. **Client overview** — industry, size, context
2. **Challenge** — what problem needed solving
3. **Solution** — what ElianaTech delivered
4. **Results** — measurable outcomes (metrics, KPIs)
5. **Testimonial quote** — direct client quote
6. **Tech stack** — technologies used

**Word count target:** 600–1,000 words each

---

### 6.6 Contact Page

**Purpose:** Make it easy to start a conversation.

**Content blocks:**
- Short intro paragraph
- Contact form (name, email, company, message, service interest)
- Email address
- Phone number (optional)
- Office location / map (if applicable)
- Expected response time

## 7. Blog / Article Strategy

See [BLOG-CALENDAR.md](./BLOG-CALENDAR.md) for the full editorial calendar.

### Content Pillars

| Pillar | Description | % of Content |
|--------|-------------|-------------|
| **Industry Insights** | Trends, analysis, market commentary | 25% |
| **Technical Guides** | How-tos, tutorials, implementation walkthroughs | 30% |
| **Case Studies & Stories** | Client success stories, project deep-dives | 15% |
| **Thought Leadership** | Opinion pieces, future predictions, strategy | 20% |
| **Company News** | Updates, events, milestones, hiring | 10% |

### Publishing Cadence

| Phase | Frequency | Goal |
|-------|-----------|------|
| **Launch (Month 1–3)** | 2 articles/week | Build initial content library (24+ articles) |
| **Growth (Month 4–6)** | 1–2 articles/week | Maintain momentum, refine based on analytics |
| **Steady-State (Month 7+)** | 1 article/week | Consistent publishing with quality focus |

### Article Standards

- **Length:** 1,000–2,500 words (long-form for SEO)
- **Structure:** H2/H3 subheadings, short paragraphs, bullet points, visuals
- **SEO:** Target 1 primary keyword + 2–3 secondary keywords per article
- **CTA:** Every article ends with a relevant call to action
- **Visuals:** Minimum 1 featured image + 1–2 inline images or diagrams
- **Internal links:** At least 2 links to other site pages or articles
- **Meta description:** 150–160 characters, includes primary keyword

## 9. SEO Strategy

See [SEO-STRATEGY.md](./SEO-STRATEGY.md) for the full keyword research and strategy.

### On-Page SEO Checklist (per page/article)

- [ ] Primary keyword in title tag (H1)
- [ ] Primary keyword in URL slug
- [ ] Primary keyword in first 100 words
- [ ] Meta description with keyword (150–160 chars)
- [ ] Alt text on all images (include keywords where natural)
- [ ] Internal links to 2+ related pages
- [ ] External links to 1–2 authoritative sources
- [ ] Schema markup (Article, Organization, FAQ where applicable)
- [ ] Mobile-friendly layout
- [ ] Page load time < 3 seconds

### Technical SEO Requirements

- XML sitemap at `/sitemap.xml`
- Robots.txt properly configured
- Canonical tags on all pages
- Open Graph and Twitter Card meta tags
- Structured data / JSON-LD
- HTTPS enforced
- Clean URL structure (no query parameters for content pages)
- 301 redirects for any changed URLs

## 10. Content Production Workflow

```
1. IDEATION        → Topic research, keyword analysis, editorial calendar
       ↓
2. BRIEF           → Content brief with keyword target, outline, audience
       ↓
3. DRAFT           → First draft written
       ↓
4. REVIEW          → Editorial review for accuracy, tone, SEO
       ↓
5. REVISION        → Incorporate feedback
       ↓
6. DESIGN          → Add visuals, format for web
       ↓
7. PUBLISH         → Publish to site, add to sitemap
       ↓
8. PROMOTE         → Social media, newsletter, outreach
       ↓
9. MEASURE         → Track performance after 30/60/90 days
       ↓
10. OPTIMIZE       → Update underperforming content, refresh data
```
